# 기생충 꼬맨틀

90개의 기생충·의용곤충 카드와 4,005개 유사도 쌍을 사용하는 정적 HTML 게임입니다.

## 실행

`index.html`을 더블클릭하면 바로 실행됩니다. 별도 설치나 서버가 필요하지 않습니다.

새로고침하거나 `새 문제`를 누르면 현재 선택한 강의 범위에서 대상 학명을 다시 무작위로 추첨합니다. 확률적으로 같은 학명이 다시 나올 수 있습니다.

정적 웹 호스팅에 배포할 때는 다음 네 파일을 같은 경로에 유지합니다.

- `index.html`
- `styles.css`
- `app.js`
- `data.js`

## 주요 기능

- 게임 시작 전 강의별 출제 범위 체크리스트
- Easy: 입력 중 등록된 영문 학명 후보 표시
- Hard: 후보 없이 영문 학명을 정확히 입력
- 0–100 유사도와 선택 범위 내 순위
- 하단 토글형 전체 학명 목록 표
- 대분류 → 강의 → 가까운 종 순의 단계별 힌트
- 정답 공유 URL
- 정답 확인 후 형태·생활사·역학·병리·증상·진단·치료·예방·기타 복습
- 모바일·키보드 접근성 대응

## 데이터 갱신

`개발 도구/build-data.js`는 `parasite-similarity.json`과 90개 Markdown 카드를 읽어 `data.js`를 다시 만드는 개발용 스크립트입니다. 실제 배포에는 필요하지 않습니다.

유사도 가중치는 강의 분류 30%, 소제목별 의미 40%, 구조화 정보 20%, 학명 관계 10%입니다.
