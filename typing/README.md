# 기생충 학명 타자연습

한글 기생충 이름을 보고 영문 학명을 입력하는 정적 HTML 학습 도구입니다.

## 실행

`index.html`을 더블클릭하면 별도 설치 없이 실행됩니다. 정적 웹 호스팅에도 그대로 배포할 수 있습니다.

## 학습 흐름

1. 시작할 때 연습할 강의를 체크합니다.
2. 한글 이름을 보고 영문 학명을 입력합니다.
3. 정답이면 다음 카드로 이동합니다.
4. 오답이면 정답 학명을 확인한 뒤 다음 카드로 이동합니다.
5. 모르는 카드는 패스하고 정답을 확인할 수 있습니다.
6. 선택한 카드를 중복 없이 모두 완료하면 정확도와 오답·패스 수를 확인합니다.

대소문자는 구분하지 않습니다. 철자, 띄어쓰기, `spp.`의 마침표는 정확해야 합니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 디자인과 반응형 레이아웃
- `app.js`: 강의 선택, 채점, 순서 섞기, 통계
- `data.js`: 90개 한글명·학명 카드
- `개발 도구/build-data.js`: 원본 유사도 JSON에서 타자연습 데이터를 재생성
